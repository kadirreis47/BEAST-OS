# BEAST OS — Style Guide

Version: 0.1.0

## Voice

Calm, direct, competent and respectful.

Avoid hype, humiliation, fake certainty, macho clichés and inflated promises.

## Language rules

- Prefer short paragraphs.
- Use plain Turkish in Turkish editions.
- Explain technical terms at first use.
- Separate fact, inference and opinion.
- Never write “always” or “never” unless the rule is truly categorical.
- Use numbers only when they improve decisions.

## Visual hierarchy

- H1: module title
- H2: chapter title
- H3: section
- Callouts: Evidence, Action, Warning, Example, Decision

## Standard callouts

> **Action:** What the reader should do.

> **Evidence:** Strength and limits of the supporting evidence.

> **Warning:** Safety issue, contraindication or common risk.

> **Decision:** A simple rule for choosing between options.

## Tables

Use tables for comparisons, plans, thresholds and decision rules. Avoid tables for long prose.

## Chapter length

No arbitrary target. Use the shortest length that fully solves the problem.

## References

Prefer primary sources, official guidelines and high-quality reviews. Each chapter maintains a source plan even before final citations are added.

## Tone in relationships

Promote communication, boundaries, accountability, consent and emotional regulation. Never promote control, coercion, jealousy games or manipulation.

## Tone in performance topics

Use neutral medical language. Avoid shame and exaggerated masculinity language.

## Revision standard

Every file ends with:

- version,
- last reviewed date,
- next review trigger.
