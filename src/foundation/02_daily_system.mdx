# Daily System

> Win the day before the day begins.

---

# Philosophy

Discipline is easier when your day already has a structure.

The objective is not to control every minute.

The objective is to remove unnecessary decisions.

---

# Default Schedule

| Time | Action |
|------|--------|
| 07:30 | Wake up |
| 07:35 | Drink 500–750 ml water |
| 07:40 | Open curtains / daylight |
| 07:45 | Bathroom & hygiene |
| 08:00 | Breakfast |
| 09:00–12:00 | Deep Work |
| 12:30 | Lunch |
| 13:00 | Walk (10–15 min) |
| 15:30 | Coffee (optional) |
| 17:30 | Training |
| 19:00 | Dinner |
| 21:30 | Prepare tomorrow |
| 22:30 | Screen off |
| 23:00 | Reading / stretching |
| 23:30 | Sleep |

---

# Morning Rules

Complete these before checking your phone.

- Water
- Light
- Movement
- Hygiene
- Breakfast
- Planning

---

# Work Block

During Deep Work:

- Phone away.
- Notifications off.
- One task only.
- Work in focused blocks.

---

# Training Window

Preferred:

Late afternoon or early evening.

Training should have:

- Warm-up
- Main workout
- Cool-down

---

# Evening Rules

Every evening:

- Prepare clothes.
- Prepare water bottle.
- Review tomorrow.
- Reduce screen time.

---

# Daily Non-Negotiables

Complete every day.

- [ ] Sleep target
- [ ] Protein target
- [ ] Water target
- [ ] Training or walk
- [ ] Stretching
- [ ] Personal hygiene
- [ ] Learning (20 min)

---

# Decision Tree

Missed training?

↓

Can you walk today?

↓

YES

Walk.

↓

NO

Perform a 15-minute mobility session.

Never skip movement twice.

---

# Weekly Review

Ask yourself:

Did I follow my wake-up time?

Did I train?

Did I move every day?

Did I waste time on my phone?

What should improve next week?

---

# Key Takeaways

Structure creates consistency.

Consistency creates progress.

Progress creates confidence.
