# Body Systems Map

```text
                 HUMAN BODY

                       │
    ┌──────────────────┼──────────────────┐
    │                  │                  │
 Nervous          Cardiovascular      Endocrine
    │                  │                  │
    ├────────────┐     │                  │
    │            │     │                  │
 Muscular     Digestive │             Immune
    │            │      │                  │
    └────────────┴──────┴──────────────────┘

             All systems influence each other.
```

---

# Why This Matters

You cannot optimize one system while neglecting the others.

Real health comes from balance.

---

# BEAST Rule

Every decision should improve at least one system without damaging another.
